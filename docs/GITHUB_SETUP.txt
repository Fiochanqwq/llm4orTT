GitHub source checkout

This private repository contains application source, documentation and tests.
experiments/, baselines/, archive/, .local/, runtime/, node_modules/, dist/,
release/ and generated outputs are intentionally excluded. They remain local.
The local distribution instructions in README.txt assume dependencies already
exist; a fresh source checkout must install and build them first.

Requirements: Node.js 24 and npm; Windows for the desktop application.
  npm ci
  npm run build
  npm run test:ci

CI runs on Windows and Linux for pushes and pull requests. It checks math formatting,
model exports, model preflight, mocked provider integrations and launcher
version handling, cloud authentication and encrypted storage, followed by TypeScript checking and the production build.
It does not require API keys, invoke paid models, run research experiments,
package desktop installers. The Linux job prepares a Python virtual environment
and runs real HiGHS regression tests and the Codespaces launch command.

GitHub browser usage: see README.md. The dev container installs dependencies
and builds on creation, then starts/reuses the service when attached. Use the
complete terminal link, keeping the forwarded port private. Runtime data and
the cloud encryption key are stored only in .local/codespace-workspace/.

npm test remains the full local regression suite. Some tests require local
experiment data, historical baselines and the solver runtime; it is not the
CI command for a fresh clone. See scripts/prepare-solver.mjs before preparing
the optional solver runtime with npm run solver:prepare.

Never commit real API keys, local workspaces, experiment data or baselines.
