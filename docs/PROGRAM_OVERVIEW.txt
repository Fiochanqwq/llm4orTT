llm4orOvO 0.7.8 · 当前程序说明
更新日期：2026-10-18；应用版本以根目录 package.json 为准。

程序提供聊天、自动优化、本地求解器与实验工作台。桌面和浏览器可连接同一工作区服务。
支持连续、整数、二元变量的LP/MILP。HiGHS随项目提供；Gurobi需自行配置。
full包含事实记录、独立模型审核、有限修复及支持范围内的预算判断；generic使用同一工具和额度环境。
保存模型请求、求解证据、最终任务状态、评分、人工答复与输出用量；可导出JSON/JSONL。
完整实验操作见 实验使用说明.txt；已完成的验证见 版本与历史说明.txt。

当前根目录双击入口使用 .local/workspace-clean；首次是空白数据，之后持久保存。
旧默认工作区 %LOCALAPPDATA%/FYPPPPP/workspace 不变。根目录入口没有迁移或删除旧账户设置。
命令行实验使用 --data .local/workspace-clean，与双击入口保持一致。
先退出旧托盘程序再启动，避免桌面单实例锁影响。

恢复与保存
保存前备份上一份已提交状态；不是无限历史，也不是断电零丢失保证。
损坏原件安全隔离后才恢复备份。隔离失败停止启动，不覆盖原件。
损坏求解/实验历史保留并跳过，界面提示。写入失败暂停新任务，修复磁盘/权限后重启。
未成功落盘的当前输出可能丢失。旧批次中断记录不自动重跑，不重写历史评分。

边界
求解和数值复核针对提交模型；语义正确性仍需独立参考及人工复核。
固定事实环境不是通用用户模拟器，非预算事实常需人工答复。
请求次数不等于费用；无金额硬限额。不同模型可能截断输出或失败，应保留失败轨迹。
API Key使用Windows当前用户DPAPI保护；正常导出不包含API Key。
研究方法版本、历史证据和第三方依赖版本具有独立含义，不统一替换成0.7.8。
