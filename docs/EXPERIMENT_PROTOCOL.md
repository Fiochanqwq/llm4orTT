# 上下文逆优化：冻结实验方案 v3（2026-10-19）

实施修订：v1的4096输出/思考token额度使猜数基线多次返回空的截断答案。在计算任何主比较得分之前停止v1，保留原记录。v2全量重新调用，统一16384 token和180秒时限，其余数据与评分规则不变。此修订针对传输可用性，不是依据得分选择模型。v1的测试还修正了评分函数对非六方案单元测试的长度兼容，正式数据仍为六方案。

第二次修订：v2在16384 token下仍频繁因思考预算截断；仍未计算主比较得分时终止。v3统一采用DeepSeek直接回答模式（thinking=disabled）、temperature=0、JSON输出、每次最多16384 token、180秒、并发4、最多90次请求，全量重新调用。按[厂商参数文档](https://api-docs.deepseek.com/api/create-chat-completion/)固定接口。v1/v2保留为传输预检记录，不计入v3得分，也不把其失败当作算法劣势。v3只能比较该直接回答基线，不能声称击败最强推理模式。数据、噪声、数学目标、评分和划分均不变。

## 研究问题与范围

在已知硬约束、已知非恒定基础成本的条件下，运营日志能否帮助选择目标特征，使少量含噪历史决策的逆优化优于直接让模型猜权重和无文本的字典逆优化？主要终点是样本外归一化决策遗憾。参数恢复和结构恢复分别评价，零残差不等于参数唯一。

当前交付是可复现的模拟先导实验，不是100个NLP4LP模型的正式结果，也不是真实人工数据。六个候选方案用二进制变量表示，必须恰好选一个；这里可枚举全部可行解，完整生成逆优化割平面。未知硬约束矩阵的恢复、一般MILP规模实验和真实用户解释评价不包含在本批实证结论内。

## 文献依据和不能越过的边界

1. [Chan等，Inverse Optimization: Theory and Applications，2109.03920](https://arxiv.org/abs/2109.03920)：逆优化背景；已核验摘要与元数据。
2. [Mohajerin Esfahani等，Data-driven Inverse Optimization with Imperfect Information，1512.05489](https://arxiv.org/html/1512.05489v2)：已查阅全文中的次优性损失与线性假设重构。本文实现经验损失加L1，不声称复现其Wasserstein分布鲁棒方法。
3. [Kitaoka，2405.14273](https://arxiv.org/html/2405.14273v8)：已查阅MILP次优性损失和有限步一致性框架。本项目用精确前向oracle割平面，不冒称复现其梯度算法。
4. [Kitaoka，2607.22263](https://arxiv.org/abs/2607.22263)：已核验摘要。它给出迭代复杂度，不是“极少样本必能恢复真参数”的样本复杂度保证。
5. [OptiMUS，2402.10172](https://arxiv.org/html/2402.10172v1)：已查阅原版全文，原版报告67题、其中13道MILP；不能把用户拟定的100题直接写成该版本事实。当前[作者数据集](https://huggingface.co/datasets/udell-lab/NLP4LP)的公开目录列出361个数值ID，尚不等于361个经过验证的可用Oracle。
6. [MAMO，2405.13144v2](https://arxiv.org/abs/2405.13144v2)：已核验摘要与元数据；一个最优解不等于K组独立上下文，不能简单复制冒充历史样本。
7. [OptMATH，2502.11102](https://arxiv.org/abs/2502.11102)：公式语义回译文本的设计参考。本批日志生成器看语义，不看隐藏数值；生成器与学习器分开调用。
8. [ORLM，2405.17743](https://arxiv.org/abs/2405.17743)、[LLMOPT，2410.13213](https://arxiv.org/abs/2410.13213)：已核验摘要或元数据；用于后续建模比较，本批未运行这些模型。
9. [EquivaMap，2502.14760](https://arxiv.org/abs/2502.14760)：已核验题名与摘要页。字典支持集F1不等于一般数学模型等价性；本批不宣称做过EquivaMap验证。
10. [I Want It That Way，2312.06908](https://arxiv.org/abs/2312.06908)：已核验题名与摘要页，交互偏好提取的相关工作，本批不实施用户对话实验。
11. [Decision Information Meets Large Language Models，2502.09994](https://arxiv.org/abs/2502.09994)：已核验摘要页，EOR解释展示参考；自动给出公式不证明解释忠实性或用户理解度。
12. [2508.10047综述](https://arxiv.org/abs/2508.10047)、[2605.20849综述](https://arxiv.org/abs/2605.20849)：已核验题名与摘要页。不能据此声称所有现有数据集都显式给定全部参数。

实验设计辅助采用 Kassis, T., Agarwal, V., He, Y., Patel, D., & Brueckner, A. M. (2026), [Scientific Agent Skills: A Library of Procedural Knowledge for Research Agents](https://arxiv.org/abs/2609.00065)，检索时当前为v2。此项是工作流来源，不是研究效果的证据。

## 数据冻结及防泄漏

配置由 `research/pilot-protocol.json` 固定。运行前保存UTC时间、配置、原始数据、随机顺序和源码SHA256。此次为本地预登记，不冒充外部注册。两个种子与遮蔽1/2/3项全交叉，共6个随机生成配置。每个配置50个上下文：前20条训练（K为嵌套前缀），中10条验证，后20条测试。四个方法用完全相同的训练样本、日志和测试输入；方法执行顺序固定随机打乱。随机数流不因方法运行顺序改变。

真实非零支持从夜班、交接、支援、加班中随机选1至3项，权重在[1,5]抽取，颜色和装饰编号为干扰项。学习器只知道统一范围[0,10]。已知工资随方案与场景变化，作为尺度锚点。每个方案的特征原始范围均为0至4，物理单位固定；不通过真值归一化特征。夜班为 max(0,夜班次数−1)；其他为线性特征。

日志生成器只见隐藏项的业务语义，既不见θ数值也不见测试集。文本学习器只见日志、公开特征字典，直接猜数基线额外见对应训练历史。所有模型调用记录完整提示、原始响应、返回模型信息、时间、token数和错误；密钥不写入研究文件。该先导实验检验闭字典结构选择，不宣称开放式任意公式生成。共最多90次请求，不以结果好坏追加请求；服务失败不以模板补成成功。

先导实验局限：技术ID中含种子及遮蔽项数编码（如m1），因此不能声称对结构数量也完全盲化；正式100模型实验必须换成不包含实验条件的随机ID。这批日志还明确标出装饰项无关，属于有利文本条件，应在后续加入含糊、遗漏及相互矛盾日志。接口temperature=0不保证跨服务版本逐字确定性，复现以封存原始响应为准。

## 数学目标与四个比较方法

前向问题为 min_x c0(s)^T x + Σ_j θ_j φ_j(s,x)，x为六维one-hot二进制向量，0≤θ≤10。次优性损失 L_k(θ)=c_θ(s_k,xhat_k)−min_x c_θ(s_k,x)。逆问题为 min_θ mean_k L_k(θ)+λΣ_j θ_j。

将每个可行方案x加入 e_k≥c_θ(s_k,xhat_k)−c_θ(s_k,x)，得到完整有限LP。HiGHS仅在证明最优时记成功。生产求解器的MILP oracle迭代方法与此枚举方法独立交叉检查；连续LP强对偶由已有边界测试另行验证。没有把连续KKT错误套用到整数变量。

- `text_sparse`：真实LLM选择字典结构，λ=0.01。
- `text_no_l1`：同一结构，λ=0，隔离稀疏正则化影响。
- `no_text_dictionary`：不读取日志，全部六项字典，λ=0.01。
- `llm_guess`：真实LLM看日志和同批历史，直接报全部六个权重，无求解器辅助。

第三项必须称“无文本全字典目标逆优化”，不能冒充“全矩阵逆优化”。同时未知A、b、c通常含双线性和可辨识性问题，需另立基线。λ此次事先固定，不在测试集选择；正式实验使用开发模型验证选择λ，并在测试模型冻结。

## 噪声、评分和结构补全

本批5%/10%/15%表示**每条历史允许的相对成本损失上限**，不是错误样本比例。对每个上下文，从损失严格大于零且不超过预算的可行方案中随机选一项；没有合格次优方案则保留最优。分别保存实际改动条数、实际改动比例和实际成本差。所有测试历史保持干净。后续若研究污染比例，必须另加Bernoulli污染率实验，不能混用两个概念。

主要评分：平均 (真实成本(学得决策)−真实最优成本)/max(1,|真实最优成本|)。同时报告未归一化成本差、隐藏项MAE、全字典MAE、全向量余弦相似度、支持集精确率/召回率/F1。余弦在零范数时为null；参数指标不与尺度/决策等价混为一谈。测试每个场景直接计算真实目标，不能使用学得目标充当评分。固定最小方案下标打破平局。

独立补全压力测试：从LLM提出的结构中删去第一项，再用K=20无噪历史拟合；反馈训练残差，允许LLM补全一次。只用独立10条验证历史的选择不一致率决定接受；验证并列时要求训练残差下降。然后才评分20条测试集。该结果单独列出，不混入主比较。一次反馈不等于证明多轮迭代已经收敛。

可辨识性审计：对K=20干净历史和完整字典，约束所有历史次优性损失≤1e-8，分别最小化/最大化每个权重，输出可行区间。区间宽说明历史无法唯一确定权重；这是条件可辨识性，不是统计置信区间。

## 统计解释和停止规则

72个数据条件×4方法=288条主比较结果，不能当作288个独立模型。实验单位是生成的基础配置，属于同一排班模型族。报告全部失败分母、成对比较、每个K与噪声层结果、6个配置的分布；本批不做显著性宣称或基于单一模型族的总体置信区间。任何小样本优势只作为后续假设，不宣称普遍优于基线。

## 正式NLP4LP 100模型阶段的准入门槛

已锁定数据版本 f0f2abb5d4fa01812ab2c818dd350f6c34041d15。文件下载返回需要授权，当前只取得公开元数据目录，真实模型求解数为0。不得绕过数据访问限制或用模拟数据填充NLP4LP计数。

获得合法数据访问后：逐模型保存源码哈希与许可证，静态检查再在隔离子进程执行；独立求解验证可行性/有界性/整数类型/参考目标；排除非线性、无有效锚点、无可遮蔽项、不可控求解时限的实例，并完整保存排除清单。按模型ID哈希固定分出开发集和测试集，在可用测试模型中选100题，若不足100明确按实际数量报告。不同上下文要改变真实输入并重新求解，不能复制同一个最优解。

正式实验在看测试结果前另冻结：100个测试模型×至少3个上下文种子×K×噪声×遮蔽项数；在模型层面做成对汇总和分层/模型簇bootstrap。主终点优先，其他终点探索性并控制多重比较。数据可用性、上下文可行性和成本预算审计通过后才启动，不预先承诺100%模型都可用。

## 复现

使用项目随附Python，依次运行 `research/pilot.py prepare`，`node scripts/research-llm.mjs logs`，`node scripts/research-llm.mjs proposals`，`research/pilot.py requests`，`node scripts/research-llm.mjs guesses`，`research/pilot.py run`，`research/pilot.py feedback-requests`，`node scripts/research-llm.mjs feedback`，`research/pilot.py feedback-evaluate`。所有阶段支持保留已完成模型调用；重新计算本地结果不产生新模型调用。任何方案修订都应创建新实验ID，保留本批原始记录。

当前批次离线重算：`npm run experiment:replay`。此入口只使用封存的模型响应，不再发送API请求。Python测试：`npm run test:research`。`research/verify_oracles.py` 独立核验300个前向MILP和12个逆问题目标一致性。`research/report.py` 生成结果页、文件校验清单与边界审计；`node scripts/research-report-qa.mjs` 检查报告筛选和手机布局。
