MATHEMATICAL DETAILS
Training sizes5 and10; seeds19 and43; noise-gap caps0 and0.1.
10 disjoint test contexts per source-seed, fixed across all methods.
The cap is true-cost loss/max(1,abs(optimum)), not10% corrupted labels.
Inverse loss is empirical suboptimality, scaled by max(1,mean absolute
known-base cost of the observed histories), plus lambda*sum(theta)/20.
Lambda0.01; theta box[0,20]. Forward LP/MILP exact-optimal status required;
tours exhaustively enumerated. Epsilon/LLM-anchor is a local adaptation,
not Wasserstein DRO. Projected subgradient uses50 updates, not an exact
implementation of another paper's different-domain theorem.
The full-bank and non-learning baselines know the design thresholds and
the missing original linear term's sign; not a prior-free full-matrix IO.
Candidate F1 is exact objective-feature agreement, NOT hard-constraint F1.

AMENDMENTS AND DIAGNOSTICS
1. ds_anchor restricted toK10 because its numeric prior sees10 histories.
2. One feedback call may receive a recorded schema/fit error when no
   residual exists (9 affected source-seed-noise combinations).
3. Clarified prompt: one call per source per correct/no/shuffled condition,
   after first-pass explanations exposed missing-price and threshold
   misunderstandings. All sources retained; no best-of-N selection.
   This is post-hoc exploratory evidence, not a fresh confirmation set.
4. solver-repair-checks.json rechecks5 addConstr failures with box-valid
   sparse cuts. They remain failures in the main results.
5. mechanism-diagnostics.json corrects ONLY oracle-known wrong cost signs
   in all4 affected clarified models, both seeds/noise caps (16 rows).
   Supplying an oracle sign is diagnostic privileged information.
   These rows are never counted as LLM successes or pooled into the main
   score table. Feature inactivity does not prove unidentifiability.
   mechanism-control.json recomputes the unchanged candidates using the
   same stable solver implementation, isolating the sign intervention
   from the engineering fix.
