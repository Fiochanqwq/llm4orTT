Order of operations
  1. Run exact-certificate/integrity tests and application tests.
  2. Type-check and rebuild the frontend.
  3. Exercise the real authenticated HTTP API in an isolated local store.
     No model credentials are needed; model calls are disabled.
  4. Freeze protocol, source bytes, runtime versions and randomized schedules.
  5. Execute the Python internal APIs with truth-free method inputs.
  6. Independently rebuild exact 2D feasible polygons and enumerate actions.
  7. Audit the full planned inventory, hashes, statuses, bounds and witnesses.
  8. Compute the prespecified stratified paired instance bootstrap.
  9. Render Chinese reports from saved data with publication_report.py.

Loopback access must be available for HTTP integration checks. A network sandbox
that denies access to the test's own 127.0.0.1 server is an environment failure,
not an algorithm outcome. Retain its log, fix the environment, then rerun the
preflight before any scientific freeze.

Evidence contract
  - The entire study has an OS-owned exclusive writer lock.
  - Atomic JSON replacement prevents truncated progress and summaries.
  - Raw cases, attempts and method results are immutable and SHA256-sealed.
  - Recorded failures are not automatically retried. An interrupted attempt
    without an outcome becomes an explicit failed outcome at resume.
  - A missing digest blocks reuse; do not reconstruct it from untrusted data.
  - Resuming never refits a saved point estimate or changes its chosen decision.
  - Source, protocol, runtime, snapshot or schedule drift requires a new batch.
  - Hashes detect accidental changes; this is not a signed public registry.
  - Historical follow-up/comparison command contracts remain supported.
    Their archived source snapshots, not today's sources, reproduce old runs.

Scientific interpretation
  This is a fresh synthetic mechanism replication, not a new language benchmark.
  There are 120 independent family-seed instances per cohort, not 2,880 or 720
  independent samples. Three generator families are fixed, not sampled domains.
  The primary contrast is dual_reuse minus full_warm_adaptive_dual at 8 LP calls.
  Noise conditions are averaged within instance; families have equal weight.
  The percentile bootstrap interval is exploratory. No p-values are selected.
  Missing, failed and unresolved runs retain their planned denominators.
  Timing is descriptive on one workstation, not a dedicated speed benchmark.
  Conditional certificate correctness is distinct from truthful model assumptions.
  A noise cap cannot repair a wrong parameter box, feature or hard constraint.
  No new LLM calls, external task scores or publication-readiness claim are made.

Reproducing from a frozen batch after source changes
  Use the frozen-source tree in a separate explicitly chosen checkout, with the
  package lock and the recorded Python/highspy/numpy/pyomo versions. A frozen
  snapshot does not vendor the runtime. For audit-only use, the independent
  verify_followup.py and verify_comparison.py require only Python's standard
  library. The regression case is copied inside the new batch.
  The report renderer needs the bundled reportlab/Pillow/pypdf runtime and
  matplotlib, plus a Chinese font; its path flags are documented by --help.
