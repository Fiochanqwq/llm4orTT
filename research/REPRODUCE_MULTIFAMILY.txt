DESIGN
Audit all source IDs41-99 before inverse outcomes: 19relocation +40tour.
Admit14 relocation and5 tours; source ID%5==0 gives3 development sources; remaining16 evaluation.
95 source-seed jobs x2 history counts x2 noise caps x8methods =3040rows.
Seeds11,23,37,53,71; K5/20; gapcap0/.1; 20test contexts per seed.
Primary K20/.1; average5 seeds within source, then equal-weight sources, separate families.
The protocol, source implementation and inputs were hashed before inverse outcomes.
Source interpretation/answer checks constrain coverage: only5of40tour candidates admitted.
No hyperparameters or test data were changed after outcomes.

LOCAL REPRODUCTION
1. npm ci
2. npm run solver:prepare
3. npm run test:multifamily
   Five mathematical tests; no research dataset or API key required.
4. node scripts/mamo-fetch.mjs
   Retrieves the pinned public source files and checks existing files before writing.
5. npm run experiment:multifamily -- --recompute
   Creates a fresh timestamped directory, freezes contexts, runs all95 jobs with5workers,
   checks recorded feasibility/arithmetic and hashes, and runs independent MTZ checks.
   Old outputs are retained. On different platforms, solver optima/choices may differ;
   compare frozen inputs, statuses, tolerances and face ranges, not just mean scores.
   Without --recompute, the default folder is resumed and existing row files are reused.

INTERPRETATION
Eight methods include two non-learning controls, correct-support diagnostic, text-selected sparse IO,
full-five-feature sparse IO, positive-floor IO, prior-center IO, and budgeted projected subgradient.
The template is controlled and has true support present; this does not test real free-form text.
Correct-support IO changes support AND regularization, so is not a clean L1 ablation.
Full-bank has5features, not an unknown full matrix. Positive floor adds external domain knowledge.
No faithful named-paper baseline reproduction, constraint F1, runtime or real-human study is claimed.
Seed min/median/max and estimated-optimal-face best/worst answer different questions.
All exploratory intervals cluster by source, have no multiplicity correction, and cannot justify broad
inference from5tour sources. A low decision regret does not imply correct parameter recovery.
See paper sections9-11 for positive findings, counterexamples, and unsupported claims.
